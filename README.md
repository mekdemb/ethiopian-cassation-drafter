# Ethiopian Cassation Precedents Intelligence & Automated Word Drafter
### የኢትዮጵያ ፌዴራል ጠቅላይ ፍርድ ቤት ሰበር አስገዳጅ ውሳኔዎች መፈለጊያ እና የፍርድ ቤት አቤቱታ አዘጋጅ (ቅጽ 1 - 28)

An AI-ready judicial search engine and automated legal pleading drafter covering all **3,246 binding precedents** from the Federal Supreme Court of Ethiopia Cassation Division (Volumes 1 through 28, the 7-Judges Plenary Bench rulings, and the 2015–2016 Special Compilation).

---

## 🌟 Key Features

1. **Dual-Language Full-Text & Morphological Search:**
   - Ge'ez orthographic normalization (handles variations in ሀ/ሐ/ኀ, ሰ/ሠ, አ/ዐ, ጸ/ፀ, ውል/ዉሌ).
   - Instant search across docket numbers, litigant names, legal subjects, cited statutory provisions, and authoritative holdings (*ratio decidendi*).

2. **Automated Microsoft Word (.docx) Pleading Drafter:**
   - Select precedents with one click.
   - Configure court name, case type (የሰበር አቤቱታ, የመከላከያ መልስ, የይግባኝ አቤቱታ), applicant, and respondent.
   - Exports formatted `.docx` legal briefs adhering to standard Ethiopian legal practice (Proclamations 454/1997 & 1234/2021) in Nyala/Noto Sans Ethiopic typography.

3. **Shepard's Citator & Overruled Precedent Tracker:**
   - Real-time warnings for decisions overruled by the 7-Judges Plenary Bench (e.g., File 242314 overruling File 41738 on period of limitation under Civil Code Art. 1845).
   - Highlights binding plenary landmark decisions.

4. **20-Year Judicial Analytics (1997 – 2017 E.C.):**
   - Interactive visual breakdown by volume, legal domain, and timeline.

## 🚀 Cloud Deployment Guide (Streamlit Community Cloud)

1. **Sign in to Streamlit Community Cloud:**
   - Go to [share.streamlit.io](https://share.streamlit.io).
   - Sign in using your Google account (`mekdemb@gmail.com`) or GitHub.

2. **Deploy the App:**
   - Click **"New app"**.
   - Select this repository.
   - Set **Main file path** to `app.py`.
   - Click **"Deploy!"**.

3. **Set Privacy (Private Access):**
   - In the deployed app, click `Settings` (gear icon) -> `Sharing`.
   - Change access from *Public* to *Private*.
   - Add `mekdemb@gmail.com` to the allowed viewers list.
